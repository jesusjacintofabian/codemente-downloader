# 🎬 Codemente Downloader

> Aplicación desarrollada en Python para descargar videos, audio y playlists utilizando **yt-dlp**, creada como un proyecto de aprendizaje con enfoque profesional.

![Python](https://img.shields.io/badge/Python-3.12+-blue.svg)
![Status](https://img.shields.io/badge/status-Beta-orange)
![License](https://img.shields.io/badge/license-MIT-green)

---

# 📖 Descripción

Codemente Downloader nace con el objetivo de aprender desarrollo de software profesional mientras se construye una aplicación real.

El proyecto crecerá por versiones, incorporando nuevas funcionalidades en cada etapa.

Actualmente permite desarrollar una base sólida para futuras características como:

- Descarga de videos
- Descarga de audio
- Descarga de playlists
- Selección de resolución
- Barra de progreso
- Historial de descargas
- Interfaz gráfica
- Docker
- GitHub Actions
- AWS
